# Changelog

Notable changes to the guide and the Home Assistant package. Dates are in ISO format.

## 1.0.0 - 2026-11-27

First public version.

- Guide: hardware and wiring, operating modes, LiFePO4 charging, Modbus register map, Home Assistant setup, state of charge and alerts, dashboard, testing and results, troubleshooting.
- Home Assistant package `drs240.yaml`: Modbus sensors, status flags, state-of-charge counter, alerts, guarded register write.
- Optional package `drs240_battery_cold.yaml`.
- Dashboard `drs240.yaml`.
- Test data from the bench (October 12–28, 2026) and from the first two weeks on site.
